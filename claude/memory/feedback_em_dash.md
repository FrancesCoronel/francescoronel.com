Avoid em dashes (—) in all user-facing copy on francescoronel.com.

**Why:** User explicitly requested removal of em dashes across the whole site.

**How to apply:** When writing descriptions, bios, tool descriptions, or any visible text, use alternatives instead:
- Colon (:) when introducing a list or explanation — "Command-line interface for GitHub: PRs, issues..."
- Comma (,) for parenthetical asides — "Blazing fast launcher, with extensions for..."
- Period (.) to split into two sentences — "AI voice dictation. Speak naturally and..."
- "that/which/where" clauses — "A tool that generates polished slide decks..."

This applies to: about page bios, uses page descriptions, skills, metadata descriptions, search hints, CTA copy, everywhere.

Previously, we would show a button redirecting the user to an ON24-hosted event page where the user could fill in the info to register for a webinar.

The goal was to revamp this flow and have the user flow to register for a webinar be baked into Slack.com directly, so it was more white-labeled and streamlined and ideally lead to a high conversion rate on signups.

- Technologies used: Hack, Less.
- Integrated the [ON24 REST API](https://on24support.force.com/Support/s/article/Connect-ON24-REST-API) on the backend to pass in form field data to Salesforce and ON24 databases
- Integrated with [AddEvent API](https://www.addevent.com/documentation/events-api) to generate calendar event links
- Added ability to modify registration
